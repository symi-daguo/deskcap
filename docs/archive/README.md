## 为什么归档而不是删除

这些记录里有**可复用的实测结论**（例如候选框坐标换算、AX 调用的真实耗时、
崩溃栈与自愈判据），排查回归时能省时间。但它们描述的是旧版本行为，
混在对外文档里会误导读者，因此单独隔离。
